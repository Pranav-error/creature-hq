# Creature HQ: codebase map

A fullstack-developer roadmap as a game: 12 phases, 177 checkpoints. A 5-question quiz clears a checkpoint,
project submissions give XP, XP sets the level, and the level evolves a companion creature.
Vanilla JS with no framework: files share one global scope. Firebase Auth + Firestore + two Hosting sites.

## Runtime flow

```
 app.html ──loads──▶ sync.js (ES module, Firebase SDK from gstatic CDN)
                        │ 1. sign in (Google / email)
                        │ 2. read users/{uid} ──▶ write into localStorage
                        │ 3. inject <script>: quiz.js → workshop.js → game.js
                        ▼
                     game.js  (reads/writes localStorage; save() → HQSync.changed())
                        │                     ▲
                        │                     └─ sync.js debounces 1.5s → setDoc users/{uid}
                        ▼
                     workshop.js ──HQSync.projects──▶ users/{uid}/projects/{id}
                        │ postMessage {type:"hq-run", html, css, js, runId}
                        ▼
              iframe: creature-hq-run.web.app (public-run/index.html)
              builds the page, sends hq-ready / hq-console / hq-loaded back
```

`window.HQSync` connects the game to the cloud: `changed`, `stale`, `local`, `user`, `signOut`, `deleteAccount`, `projects{list,save,remove,removeAll}`.

## Workshop quest coverage

`wsQuestOk(pi,si)` in `workshop.js` allows only phases 1–4 (HTML, CSS, JS, APIs), stages Tiny Wins/Project/Projects.
Phases 5 React, 6 Node, 7 Express and 8 SQL have no in-browser workspace yet.

## Known issues / candidates (found 2026-10-14)

1. No tests and no CI. `npm run check:quiz` is the only check (passes: 177 quests, 0 problems).
2. README says bump `?v=14`; the code uses `?v=16` in `build-app.mjs`, `build-site.mjs`, `sync.js` and `workshop.js`. The bump is manual and easy to miss.
3. Quiz bank correct answer is almost always option 0 (844/31/7/3). Options are shuffled on screen, so the bank is lopsided but players don't see it.
4. `game.js` is 2.6k lines of globals.
5. Workshop covers phases 1–4 only (see above).
6. The build stamps today's date into `privacy.html` "Last updated" and `sitemap.xml` lastmod on every rebuild, even when nothing changed.
